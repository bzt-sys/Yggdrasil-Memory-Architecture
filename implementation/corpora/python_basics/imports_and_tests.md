# Imports, namespace, and tests

A function submitted to an evaluator runs in a namespace. Any helper function or imported symbol used by the solution must be defined in the submitted code or available in the evaluator namespace.

Hidden tests validate behavior not shown to the model. Passing visible or mentally simulated cases is not enough to prove correctness.

When a function asks for a divisor, carefully distinguish smallest divisor, largest divisor, proper divisor smaller than the input, and the input itself.
